# 从 HighwayEnv 实践入门自动驾驶

这份路线说明方向和可观察的学习成果。当前走到哪里只看根目录 [PROGRESS.md](../PROGRESS.md)。学习者直接从实践学，Python 和领域概念在实验中补充，各阶段允许交叉推进。

**本仓库负责实际实现与实验；[vla_basic](https://github.com/chasen2041maker/vla_basic) 负责理论讲解。** 通过 [理论反向索引](THEORY_LINKS.md) 找对应讲义，不在两边重复排课，也不改变下面已有实践方向。

## 每个小节怎样推进

学习者于 2026-09-24 强调目标是逐渐熟悉整个项目并入门自动驾驶，不能持续停留在给 `demo.py` 增加功能。基础运行打通后，每节围绕一个驾驶问题，定位一个实际源码模块，解释一小段代码；需要时才回到 demo 做最小验证。规则改进与源码学习可以交叉，不以完成理想跟车策略作为进入源码的前置条件。

项目认识依次覆盖场景生成、观察、决策与控制、评估和模型训练。这个顺序用于保持方向；每次只推进一个小课题，不一次讲完所有模块。

同日用户进一步明确：疑问是 demo 如何帮助认识完整驾驶能力，特别是遇到前车后的自主变道，并非要求放弃实践。教学需说明每个实验的目的：加减速跟车连接状态、规则与动作；无其他交通的单次变道连接动作、目标车道和转向控制；遇慢车自主变道再引入邻道前后车观察与决策。执行一次变道指令不能当作已经会判断何时变道。

具体执行偏好：实验按课题放在 [demos/](demos/README.md)，保留原有练习。助手列出小段代码、说明准确位置，学习者亲手写和运行；默认不代写学习代码。源码从目录作用和所选文件开头分小节带读，不直接跳到后段。助手维护进度和证据，不把自己准备或验证的示例记作学习者完成。

2026-09-27 再次校准学习价值：读懂类与数组是工程基础，学会动作接口有助于区分决策意图、控制量和车辆运动，但读过行数不等于驾驶算法能力。每个阶段应产出可验证的小结果：预测动作效果、亲手改一个条件、解释运行变化，随后做同条件对比。近期以一次变道的执行链为重点，再进入有交通时的变道判断；当前对话继续就地带读，可复用理论资料按需引用。

## 1. 读懂并控制自己的演示程序

从 `demo.py` 的实际现象理解创建环境、`reset`、`obs`、`action`、`step` 和结束标记。通过固定动作、距离规则、速度档位、日志等小变化，练习条件判断、循环、列表、字典和函数。

可观察成果：能解释一次“观察—决策—执行—重新观察”的过程，自己修改一条已经讲过的规则，并解释运行结果。

需要原理时看：[目标速度与控制](https://github.com/chasen2041maker/vla_basic/blob/main/archive/theory/01-target-speed-and-control.md)、[step 与反馈](https://github.com/chasen2041maker/vla_basic/blob/main/archive/theory/02-step-and-feedback.md)。这是材料对应，不是新增两门先修课。

## 2. 带着问题进入源码

沿实际调用过程查找答案，每次只读本课相关的小段：

| 问题 | 源码入口 |
| --- | --- |
| 环境名称如何找到场景？ | `highway_env/__init__.py` 的环境注册 |
| 道路、车辆、奖励和结束条件从哪里来？ | `highway_env/envs/highway_env.py` |
| reset 和 step 分别做了什么，一步过去多久？ | `highway_env/envs/common/abstract.py` |
| 观察表的单位、坐标和车辆选择是什么？ | `highway_env/envs/common/observation.py` |
| 1、3、4 怎样变成车辆动作？ | `highway_env/envs/common/action.py` |
| 目标速度怎样影响实际运动？ | `highway_env/vehicle/controller.py`、`kinematics.py` |

可观察成果：能为一个现象找到相关函数或配置，并完成一个有依据的小实验。源码顺序由问题决定，不要求逐页读完整仓库。

## 3. 自己构建可解释的驾驶规则

把已有距离判断逐步发展为考虑速度差的跟车规则，理解距离、相对速度、接近时间以及目标速度变化。再学习相邻车道前后车辆检查和变道条件。

变道前先核对观察是否包含后车、道路边界和决策频率；“允许执行某动作”不等于“已经确认该动作安全”。每次修改一个主要因素，保留能够复现失败的条件。

可观察成果：学习者能够独立完成一个有限规则变化，并解释输入、判断、动作以及失败例子。需要拆成函数时再介绍函数和文件组织，不提前建立复杂策略框架。

对应原理：[观察表、相对运动与规则边界](https://github.com/chasen2041maker/vla_basic/blob/main/archive/theory/03-observation-and-relative-motion.md)。实际规则仍只在这里修改。

## 4. 用数据比较策略

把实验改为可复现的条件：固定种子集合和配置，记录碰撞、运行时间、速度与累计奖励。学习区别脚本停止、碰撞、时间上限和未结束回合，比较不同阈值和规则。

可观察成果：对同一组场景给出对比结果，说明收益、代价和证据局限。调参数使用的场景与最终检查场景应分开；不能用少量顺利回合概括所有路况。

## 5. 训练与评估第一个驾驶模型

在已经熟悉的环境上解释状态、动作、奖励、探索、回合和训练过程，再读取项目现有 DQN 示例；到实际需要时核实训练依赖和 API，不提前安装大批库。

运行一个规模合适的训练实验，保存模型，重新加载并在固定场景集合上测试。比较随机动作、手写规则和训练策略，保留失败案例并解释可能原因。

可观察成果：能自己启动和检查训练，加载模型评估，并解释奖励提高与碰撞、速度等指标之间的关系。

## 后续拓展

完成上述实践后，根据学习者兴趣拓展感知、定位、轨迹规划、控制以及驾驶 VLM/VLA。当前获得的状态表是模拟器提供的运动学数据；这些拓展有各自的新输入、任务和验证方法，不能用俯视画面或规则车代替。

## 面向智驾就业的项目成果

2026-09-24 用户明确希望以后找到智驾相关工作，并自述已有半年工程师经验。岗位原话“ageng”暂按 Agent/大模型应用工程师理解，实际技术栈待确认。以学习者实际解释和独立修改判断基础，不按工作年限自动升级掌握状态。

HighwayEnv 的官方定位是自动驾驶决策仿真环境。它适合练习观察、决策、动作执行与评估；当前观察表由模拟器提供，完整系统还涉及感知、定位、预测、轨迹规划和系统集成。参考：[HighwayEnv 官方说明](https://highway-env.farama.org/)。

沿现有实践路线逐步形成以下成果，各阶段不预设固定完成周数：

| 阶段 | 学习者应亲手形成的成果 | 验证依据 |
| --- | --- | --- |
| 读懂驾驶流程 | 说明观察如何变成动作、动作如何改变车速和车道 | 能找到相关源码，解释并修改一个小实验 |
| 完成规则驾驶 | 考虑速度差的跟车，以及检查邻道前后车后的变道策略 | 解释决策条件，展示成功与失败场景 |
| 建立仿真评测 | 固定场景、批量运行、碰撞/速度/换道等指标、失败回放与对比报告 | 同条件比较不同策略，区分调参场景和最终评估场景 |
| 比较学习策略 | 保存、加载和评估一个规模合适的 DQN 模型，与随机/规则策略对比 | 能解释数据、奖励、指标和失败；训练模型不是进入所有智驾岗位的必经前置条件 |
| 深入岗位方向 | 按实际目标补充规划控制、感知，或仿真和数据工具 | 新项目有独立贡献、复现步骤、测试、结论及边界说明 |

助手暂建议探索仿真评测或算法工具方向，与 Agent 工作中的工具调用、任务编排、日志分析和评估经验可能存在连接；是否有这些具体经验仍需核对，用户尚未选定岗位。决策规划算法方向继续补轨迹、优化和控制，感知方向则增加图像/点云、深度学习和数据评估。工程基础按需补 Python/NumPy、Linux/Git、测试和 C++，数学结合具体任务补。

例如，Tesla 的 [Self-Driving 软件验证岗位](https://www.tesla.com/careers/search/job/software-validation-engineer-self-driving-283112) 同时提到仿真数据、指标、验证工具、Python/C++ 和 LLM/Agent 工程经验。这是海外岗位职责的参考样本，不是对学习者资历匹配、当地机会或录用概率的判断。

后续可在已掌握的评测流程中加入 Agent 自动组织实验、定位日志片段和生成有证据链接的报告；碰撞等核心指标由可检查的程序计算，保留场景和随机种子。需要传感器和更完整的场景时，可评估 [CARLA](https://carla.readthedocs.io/en/latest/start_introduction/)；届时核对硬件与版本，不在当前阶段直接迁移环境。

理论方向保留于 [vla_basic 知识路线](https://github.com/chasen2041maker/vla_basic/blob/main/archive/ROADMAP.md)。如果具体任务超出 HighwayEnv 的适用范围，届时再选择实际需要的实践环境；不把理论库重新变成第二套实验工程。
